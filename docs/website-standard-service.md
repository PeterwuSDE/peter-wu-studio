# 网站标准服务：新建与 Modernization

状态：服务范围修订版。本文定义 Northline Studio 的展示网站服务；不代表新增功能已经实现，也不自动修改官网价格或已签项目约定。

## 文档与适用范围

本仓库中的本文是网站服务定义的正式维护位置；[内部交付 SOP](internal/website-delivery-sop.md)记录执行方法。外部 Canvas 可用于讨论，不作为另一份生效规范。历史设计文档保留当时背景，新增服务约定在这里维护；具体项目以双方确认的提案与合同为准。

新建网站与 Modernization 是 **Websites & modernization 内的两种项目入口**，适用于商家、专业服务、小团队与个人品牌，不限于本地门店。本地 SEO、地址、营业时间和 Google 商家资料只适用于相关业务。

## 免费检查、付费诊断与建站项目

| 阶段 | 用户得到什么 | 启动条件与成本边界 |
| --- | --- | --- |
| 免费首页 SEO 体检 | 一个公开首页的基础检查，最多两条有依据的重点发现 | 仅读取该页面 HTML 与响应头；无需留联系方式；不调用 LLM 或付费检测 API |
| 需求沟通与初步范围确认 | 判断服务是否适合、需要哪些资料、下一步如何合作 | 不是完整审计、设计或原型制作；提交联系表单不代表购买 |
| 独立付费诊断（可选） | 约定页面的证据、问题优先级与改进路线 | 确认范围、费用、交付物及约定付款后启动；不默认包含设计、开发或上线 |
| 网站项目 | 按提案完成诊断或需求梳理、设计、开发、验收、上线与交接 | 确认提案、合同及约定启动款到账后开展正式交付 |

免费体检的完整约束见[已定稿设计](superpowers/specs/2026-10-29-northline-homepage-seo-check-design.md)。它不执行浏览器渲染、Lighthouse、全站抓取、竞品分析、真实排名或 AI 推荐测试，不生成全站 SEO 总分。未检测的深入模块只能展示明确标注的交付样例，不能声称客户完整版已生成。

**付款前不启动消耗 LLM token 的客户分析或内容生成。** 联系请求只保存需求与已有扫描上下文；不会自动开启付费 API、浏览器深度采集或完整版报告。付费后的模型及第三方工具也仅能用于已确认范围与预算。

免费扫描仍可能产生托管、网络和存储费用，不宣传绝对零成本。

## 两种入口，共同交付上线网站

| 维度 | Modernization：已有网站 | 从零建站：尚无网站 |
| --- | --- | --- |
| 客户起点 | 现有网址、痛点、必须保留的内容与功能 | 业务概念、目标客户、已有品牌与素材 |
| 前期重点 | 在约定范围内盘点旧内容与 URL，识别迁移及功能依赖 | 明确定位、页面结构、素材责任和联系路径 |
| 客户提供 | 业务事实、素材使用权限，以及必要的域名、部署和系统授权 | 业务事实、品牌与素材，以及必要的域名和部署授权 |
| 最终结果 | 完成确认范围的改版网站、上线与迁移检查、交接资料 | 完成确认范围的新网站、上线检查、交接资料 |

**Modernization 默认是完整改版项目，原型是中间评审阶段。** 客户只购买诊断或设计时，提案应明确标记为独立服务，并列出不包含开发、迁移或上线。不会在尚未确认合作时默认制作多个设计方向、高保真稿或可运行原型。

## 标准网站项目包含什么

以下为服务基线；每个项目的页面、数量、集成和验收条件须在提案中列明。

| 交付项 | 标准范围 |
| --- | --- |
| 需求与结构 | 项目目标、页面清单、导航、主要行动与客户资料清单 |
| 视觉与响应式开发 | 确认范围内的页面与组件；桌面与移动端适配 |
| 内容整理 | 整理客户提供并确认的文字与素材；基础排版与约定的轻量润色 |
| 联系路径 | 清楚的联系方式与行动入口；如包含表单，明确字段、接收方式并验证送达 |
| 基础 SEO | 页面标题、描述、语义结构、索引设置；按适用范围提供 sitemap、canonical 和结构化数据 |
| 基础可访问性 | 对比度、键盘操作、焦点、表单标签及图片替代文本检查；不声称完整合规认证 |
| 部署与上线 | 约定环境的域名连接、HTTPS、部署及上线检查 |
| 改版迁移 | 约定 URL 清单的处置、相关内容迁移与核对；业务数据库另定范围 |
| 交接 | 已交付内容、部署与账号责任、必要操作说明；有 CMS 时提供约定的更新说明 |
| 缺陷保障 | 上线后 14 天，修复不符合已确认交付要求的缺陷 |

网站可以采用静态内容方式；**可编辑 CMS 或管理后台不是默认交付物**。如客户需要自行更新，应在报价前明确编辑对象、角色、频率、平台、培训和费用。未提供 CMS 时，交接需说明后续内容更新如何办理。

## 合作与交付流程

1. **初步沟通：**确认目标、预算适配、业务类型和所需资料；可先使用免费首页体检。
2. **范围与启动：**明确交付、不含项、费用、客户责任、评审轮次、验收与时间线；确认合同及约定启动款。
3. **盘点或需求发现：**改版做授权范围内盘点；新站整理客户资料。发现隐藏复杂度时，先提出变更并确认。
4. **结构与设计：**确认页面、URL、内容责任及视觉方向；按约定提交设计或预览并收集集中反馈。
5. **开发与验证：**完成范围内页面和集成，核对内容、关键路径、迁移和质量检查。
6. **验收与上线：**客户确认范围内成果，满足项目付款及上线条件后执行发布与复查。
7. **交接与保障：**提供交接资料与 14 天缺陷修复保障；客户可自行接手或另选 Care。

需要先通过付费发现阶段才能估算的复杂项目，应把发现阶段与后续实施分别报价、分别确认；不在未知范围下承诺固定总价。

## 验收与效果边界

验收依据是已确认的交付物和可复现测试，不以搜索排名、收入或第三方平台处理速度作为付款或上线条件。

- 页面与内容：约定页面齐全，无占位内容；业务事实、联系方式与素材由客户确认。
- 交互与联系：约定设备和浏览器下导航、链接、表单与集成完成关键路径测试；表单验证实际收件。
- SEO 与迁移：为清单内 URL 逐项记录保留、迁移、合并或删除；保留地址继续正常访问，变化地址映射到相关替代页，没有替代内容的删除页可返回 404/410，不统一跳到首页。
- 索引与平台：应公开收录的页面无意外 noindex；应保持私密的页面不移除限制。Search Console 授权或提交仅在约定范围内完成，不保证何时收录或何时出现平台数据。
- 性能：提案约定测试页面、环境、工具及版本、运行方式和目标；实验室 Lighthouse 与真实用户 Core Web Vitals 分开报告。没有真实用户数据就标为暂无数据，不据此宣布达标或失败。
- 可访问性：有信息价值的图片提供合适替代文本，装饰图片允许空 alt；自动化检查配合关键路径人工检查。
- 外部依赖：记录第三方脚本、系统、平台及其对测试或上线的影响；未达约定目标的例外须双方确认，不单方面豁免。
- 安全与业务：可报告实际检查的公开配置与测试结果；不把安全响应头或前台检测当成全面安全审计。不保证特定排名、流量、获客、收入或 AI 引用。

## 变更、14 天保障与 ongoing care

上线后的 **14 个自然日**为交付缺陷修复保障期，自双方确认的生产上线日开始计算。期间反馈、经核实属于原交付范围的缺陷免费修复，不占用 Care 修改额度；修复可在保障期后完成，不因处理跨期重新收费。保障不等于全天候响应或固定修复时限。

| 请求类型 | 处理方式 |
| --- | --- |
| 原交付不符合确认要求，例如我们交付的表单无法送达 | 保障期内反馈并核实后免费修复；无需购买 Care |
| 替换图片、营业时间或活动内容等需求变化 | 有 Care 时按适用修改额度处理；无 Care 时单独报价 |
| 新页面、额外语言、新后台或业务功能 | 先评估范围、费用与时间，经书面确认后执行 |
| 客户或其他人员更改、第三方服务变化引起的问题 | 先查明原因，再按维护约定或另行报价处理 |

客户迟交素材或迟于约定时间反馈，会影响时间线；调整后的日期应确认。超出约定轮次或已确认范围的修改，先说明影响，再开始执行。

Care 为可选服务。现有官网约定为：Care 每月最多 1 小时小型内容修改；Care Plus 每月最多 3 小时；额外工作按现有小时费率，未用额度不结转，最低合作期 3 个月。价格与完整条款见[Care 页面](../app/care/page.tsx)，本次不改变。持续 SEO 与新增功能不默认包含在 Care 内。

## 客户资料、授权与账号

- 客户确认资料真实性及素材使用权；我们不编造评价、资质、案例或业务成果。
- 免费首页体检与项目深度采集使用不同权限和成本边界。公开内容盘点不读取登录区、会员、订单或表单提交。
- 私有业务数据迁移仅在独立确认的范围、授权、最少必要访问和保留期限内执行，不交给公开网页爬虫。
- 域名和第三方账号原则上由客户持有，我们通过必要授权协作；如需代管，提案明确所有权、续费与退出交接方式。第三方订阅、主题、应用、字体和交易费用单列。
- Before / after、客户名称、截图和成果用于公开营销，需另外取得书面许可；购买服务不等于同意公开。
- 项目资料的保存、删除、访问权限与交接责任在提案中写明；不将私有数据默认发送给模型或外部工具。
