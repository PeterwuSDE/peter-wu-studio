# Service page visual sections

User request: the subpages are too text-heavy and read like image-free flyers. Make their sections distinct and attractive. Direct main updates are already authorized for this repository.

Approach: retain Northline's warm paper/cobalt brand and existing commercial terms. Replace continuous explanatory blocks with four named zones: introduction with a large visual, practical outcomes, scope/fees, and a next step. Add accessible in-page navigation. Use two original generated material/product images in illustrative browser compositions; use readable calendar, report and care-dashboard concepts for the other services. Never present concepts as real customer work, operational metrics or a functioning SEO checker.

Implementation: shared ServicePage presentation components; reorganize Websites, Tools, Shopify, SEO and Care pages; add scoped responsive CSS. Collapse secondary detail with native details/summary. Keep important prices and care terms visible. Preserve existing URLs, metadata, email, schema and legacy /websites anchors. No backend or payment changes.

Validation: production export; rendered route, anchor, image, metadata, pricing and disclosure checks; independent read-only review. Browser availability must be reported accurately. Publish by updating main with a lease after checking its current SHA, then inspect Vercel deployment status.

Review: corrected scroll margins for every service hash target, including legacy div/link/article anchors. Margins add only the jump bar plus breathing room because root scroll padding already accounts for the header. Asset delivery uses quality-85 WebP encoding, approximately 109 KB per image; full-resolution originals are retained outside the production directory. No browser tool is available, so visual fit and runtime scrolling are not claimed as tested.
